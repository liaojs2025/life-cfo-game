# 模块变更记录

本页保留各版行为与规则梗概。详细历史可查 Git；当前范围见 [PRODUCT](PRODUCT.md)，数据见 [DATA](DATA.md)，验证证据见 [AUDIT](AUDIT.md)。后续记录应包含日期、模块变化、存档影响、验证结果和遗留限制。

## 2026-11-16 · v0.1 · 十二年核心循环

- 建立 2007–2018 十二个年度、家庭选项、四类金融资产、税后工资与生活收支；资金困难时提供暂缓出口。
- 加入医疗保障、自住房按揭、购车与折旧，分列贷款本金、利息与交易费用，逐年核对净资产变化。
- 提供自主、规则辅助、规则托管、固定策略对照、年度复盘和结局；初版顾问不调用外部模型。
- 完成响应式主界面、联动滑杆、财富曲线、自动存档、重放核验、JSON 导出与已知剧情标记。
- 建立背景、产品规划、数据口径和独立 audit agent 维护约定。十二年浏览器路径与移动布局完成验证；旧现金下限规则已在 v0.2 移除。

## 2026-11-16 · v0.2 · 行业配置、情报与完整账本

- 新增科技、消费、医疗，底层扩为七资产；界面保留四张主牌，股票方向可选。行业代理采用 French 研究组合。
- 删除应急储备设定与隐含现金下限，0% 现金合法；维持持仓不执行目标比例，实际付款不足仍触发卖出或缺口借款。
- 新增年初三条资讯与市场数字、完整年初／年末资产负债快照；生活目标改为全程无缺口借款。
- 新增回合地图、生活事件卡、生活计划、历史现场、时代相册与展示徽章。徽章依据真实持仓和实际经历，不提供收益加成。
- v2 采用独立存档，v1 原档保留。独立审计、十二年浏览器通关、旧档保护、图片加载与手机布局完成核验。

## 2026-11-16 · v0.3 · 二十年与 AI 独立账户

- 扩展至 2007–2026 二十轮、30–50 岁；2007–2025 为历史市场，2026 为架空情景。2019 年行业代理切换为 SEC 披露的 XLK/XLY/XLV，明确数据断点。
- 加入玩家自配模型、人机共用匿名情报、一次回答提供双方决定、当年封存、失败显式规则替补及固定网关转发。
- 新增同桌独立家计与持仓、双账本原子结算和逐年联合重放，三模式继续适用。
- 新增固定 55 种虚构策略参照；严格超过比例与并列百分位分开，无本金不排名。
- 通关画像由模型选择真实证据 ID，程序绑定年份与原文，要求至少三个不同玩家回合；规则画像明确标注来源。
- v3 存档保存双方状态、顾问包和画像，密钥只留内存；v1/v2 原档封存。模拟接口二十轮浏览器路径、有限真实年度与画像请求完成验证，两类证据分别记录。

## 2026-11-16–17 · v0.9.0-rc.1 · 接口可靠性与公共试玩

- 支持基础地址和完整接口规范化、JSON 围栏与文本数组响应；模型仅引用情报 ID，由程序绑定观察，合理家计数字不再误拒。
- 画像允许引用对应已完成年份，继续拒绝错误日期、虚构事实和收益承诺；补齐字段与数组边界提示，不放宽校验。
- 固定中继通过 POST 请求体临时接收凭证，避免与站点认证头冲突；不跟随重定向、不注入模型 token 上限、不回显原始错误正文。
- EFUND 上游 SSE 有界聚合为普通 JSON；完整流受超时和大小限制，实际工具调用、截断与密钥回显拒绝。
- 参数兼容、非 JSON 520 和响应头前连接重置恢复共用最多三次请求与六十秒总预算；服务端每次只转发一次。界面提示次数与可能重复计费。
- 区分“回答未通过核验”和网络连接失败；无长度头的超限响应仍正确归为大小错误。诊断只记录固定类别、阶段与耗时。
- 新增 GitHub Pages 静态构建和 Actions，保留 Sites 公共中继；素材主题覆盖科技、体育、健康、物价等，照片／图解／模拟封面分别标识，首屏采用本机字体。
- 财务规则、市场数据、v3 存档键和旧上下文标识不变；已封存结果继续核验恢复。
