## 背景与定位

投资入门产品常把财富变化简化为收益排名，忽略工资、消费、保障、负债和家庭责任。人生 CFO 通过连续选择解释这些因素如何共同改变财富与生活：同样的市场涨跌，遇到不同的家庭安排，会产生不同的结果。

长期方向是从初入职场到退休的约 60 次关键选择，覆盖全球事件、个人经历和多种决策模式。当前版本聚焦一条能完整游玩和核对账本的家庭成长线，不宣称已经模拟完整退休人生。

首章面向中文用户，使用美国资产背景与美元计价的虚构港湾城家庭。统一币种减少首版的汇率、跨境限制与地区税费负担。角色、工资、房价、车辆、保险和家庭事件均为教学模型，不代表中国家庭真实投资条件。

## 当前体验与差异化

- 每年看公开情报和家庭对话，安排家庭方案、投资牌与保障。工资变化、照护和陪伴都有代价。
- 同一次模型请求给玩家建议与同桌决定；双方从同一起点，在同一市场及外生事件下独立演化。
- 成功的模型回答在本轮封存，刷新、改模式或改连接不能重抽。失败可以重试，也可明确选择规则陪练。
- 年度账本区分家庭净投入、资产变动、贷款本金和利息，不把工资包装成投资收益。
- 年度参照来自虚构策略池；最终画像引用真实执行记录，只描述游戏行为偏好，不推断现实心理或预测能力。

## AI 请求、封存与密钥

接口接受 `endpoint`、`baseURL`、`baseUrl` 或 `base_url`，可填基础地址或完整 `/chat/completions` 地址，程序补齐兼容路径。`getApiProviderHint` 为已识别供应商返回默认模型与地址提示；显式模型名原样保留，账号是否有权使用仍须由上游确认。只允许 HTTPS 或本机回环 HTTP，不跟随重定向。正常全程为每回合一份成功决定加通关一份画像；失败或兼容重试可能产生服务商费用。

`dist/providers.js` 保存 8 条固定上游路由：EFUND、OpenAI、DeepSeek 两种路径、DashScope 中国/国际、智谱和 Moonshot。地址规范化后精确匹配白名单则经受控中继，不能仅因域名相似就转发。未知自定义端点由浏览器直接调用，须支持 CORS。已知供应商的默认模型提示不是实际可用性保证，也不代表所有路由均完成真实凭证测试。

Paratera 使用单独的 `DIRECT_PROVIDERS` 预设，根地址和 `/v1` 均规范化为 `https://llmapi.paratera.com/v1/chat/completions`，由浏览器以 Authorization Bearer 直连，不经过 Worker/Node。新局及快捷预设依据用户截图填写 `DeepSeek-V3.2-Instruct`；显式自选模型和已有存档 `apiPreference` 保持。它不继承 EFUND 的 SSE 和 520 自动恢复，401 不重试。

客户端仅在当前页面内存保留 API Key，不写入 localStorage、存档、导出或仓库。固定中继调用将 `{provider, apiKey, request}` 放入 HTTPS POST JSON 请求体；中继按路由 ID 选择固定上游，并使用 `Authorization: Bearer …` 转交密钥。中继不保存或缓存凭证与回答，不记录凭证、请求正文或原始响应正文，并拒绝任意代理目标。密钥会经过中继服务器，因此不宣称纯浏览器直连或服务端不可见。端点与模型偏好可以保存，刷新后为未封存回合重新输入密钥。URL/模型夹带凭证和响应密钥回显继续拒绝。本轮公开摘要和虚拟家庭账本会到达选定服务商。

已部署的静态前端是 [GitHub Pages](https://liaojs2025.github.io/life-cfo-game/)，现有 [Sites 站点](https://life-cfo-investment-lab.sapphirevale1.chatgpt.site) 承载公共 `/api/ai` 中继，本机开发服务提供自己的同源路由。发布产物分别由 `build:pages` 和 `build` 生成，不内置用户密钥。页面与公共跨域入口已部署；完整模型流程、新增有限恢复及各供应商实际兼容仍待最终实测，不以 v0.3 的旧站验证替代。

已部署的 EFUND 传输仅向固定上游发送 `stream: true`，中继读取 SSE 后合成为原有普通 JSON 响应，浏览器仍提交非流式请求。每次中继只调用上游一次；55 秒限制覆盖接收整段流，不在收到首字节后重置。SSE 原始传输最多 2,000,000 bytes，聚合 JSON 最多 200,000 bytes；非 EFUND 或上游忽略流式要求返回 JSON 时仍按 200,000 bytes 读取。它不改变客户端三次总请求和 60 秒总预算。安全诊断仅保留固定枚举和严格格式标识；流式失败增加固定原因分类，不记录凭证或原始正文。部署不代表公网故障已解决。

独立 Node 中继作为可选产物复用同一固定路由和安全处理器，默认并发 8、完整请求 60 秒，上游仍为单次 55 秒；只提供 `/api/ai` 和 `/healthz`，不托管源码或内置模型密钥。[部署指南](DEPLOYMENT.md) 保留供自托管使用；当前 Paratera 直连无需 Node 主机，`PUBLIC_RELAY_ORIGIN` 继续保持原 Sites。

年度请求只发送人工匿名公开摘要、双方当前资产负债、预算、可选方案和固定规则。它不含真实年份、来源 URL、未来行情、未发生事件或完整历史序列；玩家在完整情报中可看到同样的摘要。模型禁止调用外部工具或凭记忆补齐结果，但匿名化不能证明模型已经忘记历史。

模型分析返回 `signalId`，程序据编号绑定白名单中的真实观察原文；推理和风险仍做独立内容检查。支持纯 JSON 对象与只包裹合法 JSON 的 Markdown 围栏，不接受任意前后叙述。HTTP 400 明确拒绝可选 `response_format` 或 `temperature` 时最多进行一次参数兼容重试；与下述临时错误恢复共用总请求预算。七类配置、家庭方案与购置能力由引擎校验。非法比例、虚构或冲突观察、未来行情断言或不合法格式仍明确失败，不会静默变为规则成功。编号可追溯不证明自由推理正确。

### 有限恢复契约（本轮重新审计）

客户端同一次用户操作最多 **3 次总 fetch**，包含首次请求、最多 1 次 HTTP 400 可选参数兼容重试，以及符合条件的临时错误重连。服务端每次只发送一份上游请求；没有服务端重试循环，不形成服务端三次乘客户端两次的六次放大。

临时恢复只允许精确匹配的受控 `efund` 中继响应：客户端收到 HTTP 502，JSON 错误字段为 `code === upstream_error`、`upstreamStatus === 520`、`upstreamReason === non_json`。上游状态由中继的实际响应记录，不能从用户或模型文字推断。满足条件时按已用请求次数退避 1 秒或 2 秒，仍受剩余三次总预算约束；例如先发生 400 兼容重试、第二次再遇符合条件的 520，则等待 2 秒后才能发起第三次请求，不另开三次额度。只有真正发起下一次 fetch 才通知 UI 更新尝试次数；取消退避不虚报一次重连。

认证/权限拒绝、额度不足、网络抛出异常、上游 JSON 格式 520、其他供应商、直连请求和不符合全部字段的响应，不进行此类临时恢复。合法 400 参数兼容是独立的一次性分支，不把这些错误泛化成可重试失败。模型输出 JSON 无效、未来信息或非法决定同样不得借重连绕过校验。

客户端同次操作使用 60 秒总计时，覆盖请求及等待，重连不重置；Worker 每个请求单次 55 秒上限。取消需同时终止进行中的请求或退避，迟到响应不得继续封存。UI 预告重连可能重复计费，并显示重连次数。游戏不内置密钥或费用额度；请求次数、请求/响应大小和超时限制用于约束执行，不构成费用封顶。

成功包保存来源、配置模型名称、稳定上下文标识、分析和双方决定。本轮成功封存后，改连接只影响下一轮；玩家仍可修改自己的建议。双方先在临时状态结算，全部成功后一起更新。恢复存档时，按每年当时双方状态校验顾问包，再核对同桌实际执行。

画像在通关后生成，至少引用三个不同回合的玩家事实。模型只返回证据 factId 与解释；程序按该编号绑定真实年份、玩家账户和完整原句，避免模型复写长句失真。若响应额外提供年份、账户或原文而与实际不符，仍明确拒绝。保存态继续核验绑定事实与上下文；配置证据取交易后的实际比例。成功模型画像不重复抽样，规则画像明确标识。模型内容经校验并按文本转义展示，不能作为 HTML 执行。

## 初始家庭、目标与得分

林舟 30 岁，与伴侣阿宁生活在港湾城。初始净资产 $100,000、无负债：现金 $60,000、宽基 $20,000、国债 $15,000、黄金 $5,000，三个板块为 0。税后年工资 $72,000，基本年支出 $36,000，其中租金 $18,000。

工资按模拟假设每年增长 2.5%，生活费用上涨 2%。选择带来的工资或支出增量从下一回合生效。生活值初始 50，范围 0–100，复盘显示受上下限约束后的实际增量。若两项家庭方案均买不起，增加零成本暂缓选项、生活值 −2，避免困难路径无法推进。

阶段目标：20 年全程无现金缺口借款、挑战净资产 $1,000,000、生活值达到 75。无缺口要求当年无新增且年末无遗留缺口借款，房贷不计入；生活目标还要求期末无缺口借款。

综合分由财富最多 35 分、生活最多 25 分、无缺口年度比例最多 20 分、投保年度比例最多 20 分组成。每个新增缺口年度减 8 分，期末仍有缺口借款再减 20 分，最终限定 0–100。财富分按净资产/$1,000,000 封顶；持有现金本身不加分。这是教学反馈，不是现实财务建议或人格测量。

## 结算与比较契约

1. 展示年初账本、当前公开情报和家庭选项，准备并封存同桌决定。
2. 支付人生方案、房产首付与费用、车辆购款；不能用尚未到账工资支付年初购买。
3. 年度再平衡按七类比例执行；hold 不执行目标比例或补现金，只为已选实际支出筹资。
4. 计算金融回报、房价变化和车辆折旧，再结算工资、生活、保障、医疗、按揭与事件。
5. 年末现金不足时按比例卖出非现金金融资产并收费；仍不足形成缺口借款，下一年起按 12% 收息。结余先偿还缺口借款。
6. 保存双方快照、归因与来源，揭晓本年情境，再进入下一年。

净资产为七类金融资产加房车、减按揭与缺口借款。每年严格核对：`期末净资产 − 期初净资产 = 家庭净投入 + 投资与资产变动`。房贷本金是资产负债转换；金融收益、房价变化、车折旧与交易费归入资产变动。

快照包含九项资产和两项负债，时点为本年交易前及全年结算后。余额差包含买卖与工资，不能叫作逐项收益。金融指数、双方年度收益与模拟参照均使用税费前金融组合回报，剔除工资、房车和家庭开支；回撤只观察年末。

参照池不含玩家本人：`strictBeatPct` 只计收益严格低于玩家的策略，并列不算“超过”；`pct` 百分位将并列按半个样本计。浮点相等容差为 1e-10。无年初金融本金则两个值均为空、不排名，不让空账户在熊市虚获胜。

## 数据与可复现性

产品版本升级为 v0.9.0-rc.1，但固定数据版本仍为 `harbor-2007-2026-v3`，财务状态版本 3，浏览器主存档键仍为 `life-cfo-save-v3`。市场不因系统日期、实时报价或抽奖改变。同起点与已封存决定序列可以重放；外部模型再次生成不保证相同，因此复盘读取保存结果，不重问过去决定。

科技、消费、医疗在 2007–2018 使用 French 五行业研究组合，2019–2025 改用 SEC 披露的 XLK/XLY/XLV 代理，存在产品和行业范围断点，不能宣称同一连续不变指数。宽基、国债、黄金来源与各年口径详见 `DATA.md`。2026 全部回报明确为架空情景。

规则陪练配置固定为现金20/宽基20/科技8/消费6/医疗6/债券30/黄金10，只依据当前家庭情况安排人生与房车，不按未来赢家优化。固定均衡和全现金基准保留。各路径家庭选择独立，因此严格隔离配置效果的实验仍未实现。

静态前端包含全部剧情数据，无法阻止阅读源码、熟悉历史或修改本地存档。保存核验用于发现不一致，不是竞赛级防篡改认证。

v0.1 验证十二年核心循环；v0.2 增加行业、完整账本与历史相册，并按用户要求删除现金下限；v0.3 扩展二十年、可配置真实模型、事前封存双人路径、模拟参照与证据画像；v0.9.0-rc.1 保留财务 v3，改进基础地址兼容、观察绑定、固定供应商转发、发布结构与时代主题。原始 `outline.md` 保持不改，逐字快照保存于 `BACKGROUND.md`。
