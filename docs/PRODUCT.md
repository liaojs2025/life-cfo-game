更新于 2026-11-25。产品面向希望看懂投资与家庭现金流的玩家。原始背景见 [提纲](BACKGROUND.md)，逐次演进见 [模块记录](MODULES.md)。

## 当前体验

| 玩家问题 | 产品设计 |
| --- | --- |
| 我从何时开始？ | 美国、日本各有近十年和过去四十年，两种长度都到 2026 年 9 月 30 日。 |
| 当时能知道什么？ | 每年展示一张上一年新闻照片，以及依据截至开年已公开事实编写的简报与上年涨跌。 |
| 我能买什么？ | 宽基、现金、黄金、债券、三个行业股票。指数独立用于比较。日本早年海外敞口与本土行业切换对应实际历史来源。 |
| 家庭与对手如何行动？ | 年初配仓，每期共同经历家庭现金流。两名对手按不同股票仓位约束独立交易。 |
| 我如何复盘？ | 投资和净资产曲线、年度账本、夏普与回撤、关键决策画像、可打开的历史新闻和事件传导图。 |
| 如何继续？ | 国别和长度组成四个存档位，保留旧三十年以及港湾城入口。 |

## 维护方向

每年更新共同截止日、行业代理和图片档案。新增年份须先取得可复算行情及有日期的历史材料。跨来源或跨币种使用代理时，逐年保留投资标的、计价、收益类型和取价日。结算和恢复集中在同一引擎，双对手和玩家使用同一套市场与家计规则。

## 三十年旧版的财务与人生规则

新玩法的唯一结算实现为 `dist/campaign.js`。每年顺序固定：

1. 校验全部配置与两种对手风格约束，按非现金买卖成交额收取每侧 0.1% 费用；求出扣费后可投资本金。
2. 对年初实际配置应用全年资产回报。年末才入账的工资或遗产不参加当年投资。
3. 三账户记入同一份工资、遗产、生活与事件净现金流；现金不足时按比例卖出非现金资产并计费。
4. 资产仍不足支付时保留未付负债。净资产不大于零即出局；玩家出局结束旅程，对手出局后封账，不接受下一年的收入或投资。
5. 保存快照、下一年家计与实际决定。

恒等式：**年末净资产 = 年初净资产 + 投资损益 + 家庭净流入 − 交易与变现费用**。

家庭种子与配置无关。同一种子和国家重放会得到同样的起始年龄、家庭事件与收支。婚姻、遗产只发生一次，生育不超过两次并有年龄与间隔约束；退休阶段会降低家庭收入。家计起点、每年 2.5% 的名义工资趋势和事件金额都是教学设定，不能当作当地真实医疗、税制或工资统计。

生活费调整使用世界银行 WDI／IMF IFS 的美日年度 CPI 通胀值，保留日本通缩年份。1994–2024 原始响应和哈希存于来源快照；当年数值不进入年初情报，在结算后调整下一年的生活基数及价格指数。这是年度步进模型，不声称全年 CPI 在当年最后一天已经发布，也不复原逐月家庭账单。工资暂未取得同口径完整名义本币序列，继续明确模拟，不混用 PPP 不变价工资。

收益指数逐年复合实际年初配置的扣费前回报，排除家庭出入金；另有同起点、同家庭现金流、零费率的主指数基准账户供核账。美国标普含分红，纳指、TOPIX、日经为价格回报；日本黄金包括日元汇率变化。详见 [DATA30](DATA30.md)。

终局指标由 `atlas-risk.js` 从已完成的年度回报统一计算：年化收益采用几何复利，波动率取年度样本标准差；夏普为年度超额回报的算术均值除以这些超额回报的样本标准差。参考利率可选历史隔夜利率近似、游戏现金 0% 或自定义固定年利率，不写回投资与家计。最大回撤只观察期初和年末峰谷，不能代表年内最大跌幅；出局对手的统计截止出局年，必须同时显示样本数。少于两年、零超额波动等不可计算情形留空，不给出虚假的无穷大评分。

历史参考默认采用 OECD／FRED 美日隔夜银行间利率月序列，每年十二个月报价取算术平均并转为小数；它是事后绩效的短端利率代理，包含银行间信用及流动性近似，不等于无风险可交易现金的实际复利。序列与原始月度快照见 `history30-rates.js` 和 [DATA30](DATA30.md)。峰谷年份可跳转至曲线谷底，连起统计指标与实际年度经历。

## AI、封存与复盘

年初请求只使用公开材料、当前资产和家庭预算，不提供当年市场结果、未发生人生事件、资料 URL 或完整历史数据集。匿名摘要尽力减少历史识别线索，但不能保证模型不会从训练记忆识别年代。

一次回答提供三个建议配置，两位对手按各自风格约束执行；玩家可以修改自己的部分。程序按资讯 ID 绑定观察原文。非法配置或错误引用明确失败，不自动修成成功，也不隐式更换模型或规则来源。请求开始时冻结账本；界面用请求代际阻止迟到结果覆盖新局。

复盘依据实际执行记录，规则版本选取回报较弱、调整较大和现金流紧张的年份，解释市场与家庭的共同影响。模型还会收到两位对手逐年的实际仓位、收益及出局状态。证据 ID 由程序绑定年份与原文；一两年即出局时按已有记录数引用，不虚构三年经历。

单条模型证据解释含无法核验的数值时，可局部回退为程序依据该年真实账本生成的说明，并标记 `interpretationSource: ledger`；其余有效内容保留。恢复存档要求该说明与重新生成的账本说明逐字一致，不能把篡改文字混作程序事实。

DeepSeek 为默认服务，另有 EFUND、OpenAI、GLM、Kimi。密钥只留页面内存，经固定中继临时转交；只保存地址和模型偏好。成功年度包封存，切换服务不改写旧决定；刷新后的新请求需要重新填写密钥。调用上限及服务差异见 [RELEASE](RELEASE.md)。

## 双入口与存档边界

- 主入口 `index.html` → `atlas.js` → `campaign.js`，新账本版本 4，按国家使用 `life-cfo-atlas-1-` 键保存。
- 旧入口 `legacy.html` → `app.js` → `engine.js`，继续原 v3 财务与存档，市场覆盖 2007–2026，末年为模拟。
- 新主玩法不迁移旧家庭资产，不把历史版本的费用、生活值、保障或借款规则混入新账本。
- 当前没有新玩法文件导入、导出或跨设备同步；损坏存档需用户确认后才能重开替换。
