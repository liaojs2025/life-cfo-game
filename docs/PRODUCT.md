# 人生 CFO · 产品规划

版本：**1.0.0 正式版** · 更新：2026-11-17

背景参考：[原始提纲快照](BACKGROUND.md)。本页维护产品范围与后续方向，数据和参数见 [DATA](DATA.md)。

## 背景与定位

投资入门产品常把财富变化简化为收益排名，忽略工资、消费、保障、负债与家庭责任。人生 CFO 让玩家通过同一家庭的连续选择，理解这些因素如何共同改变财富与生活，并通过完整账本解释结果。

长期方向是从初入职场到退休的约 60 次关键选择。v1.0 聚焦一条二十年成长线：中文界面、美国资产背景、美元计价、虚构港湾城家庭。投资与家庭取舍相连；AI 给建议并管理独立账户；时代影像与年度复盘让历史背景和财富变化可读、可回看。

## v1.0 产品范围

| 模块 | 当前体验 |
| --- | --- |
| 二十年旅程 | 30 岁、10 万美元起步，2007–2026 共 20 轮；每年两项家庭方案，资金困难时可暂缓。2026 为模拟终章。 |
| 年初情报 | 政策、行业和社会简报，带时点的市场数字，以及人机共用的匿名摘要；年末揭晓当年结果。 |
| 投资配置 | 四张主牌对应现金、宽基、科技、消费、医疗、国债、黄金七类资产，总计 100%；支持再平衡或维持持仓。 |
| 生活计划 | 医疗保障、自住房按揭、购车与维护折旧；没有现金下限，支出不足时卖出金融资产或形成缺口借款。 |
| 三种模式 | 自己玩、搭档建议、搭档托管；托管执行针对玩家账户的建议，玩家手动推进回合。 |
| 多服务 AI | DeepSeek / EFUND / OpenAI / GLM / Kimi 固定中继；默认 DeepSeek deepseek-flash，各服务自动填入模型与地址，EFUND 默认 deepseek-v4-flash 并关闭思考模式。 |
| 具体分析 | AI 引用本轮情报，给出配置判断、家庭方案、理由与后续观察重点；玩家可查看、采纳和修改。 |
| 独立同桌 | 双方同起点、同市场，各自选择家庭方案和配置；决定先封存，结算同时提交。 |
| 完整复盘 | 金融回报、家庭收支、九项资产和两项负债的年初／年末余额，以及财富曲线。 |
| 模拟策略排名 | 固定 55 种模拟策略，按同年税费前金融回报比较；并列不计超过，无本金不排名。 |
| 行为画像 | 真实 AI 或规则生成本局风格总结，引用至少三个不同回合的实际选择。 |
| 时代收藏 | 回合地图、相册和展示徽章；照片、历史图解与模拟封面分别标识。 |
| 保存与导出 | 浏览器自动保存、双账本重放核对、JSON 留档和旧版原档封存。 |

三个挑战是全程无缺口借款、净资产达到 100 万美元、生活满意度达到 75 且没有未偿还缺口借款。住房按揭不计入缺口借款，未完成全部挑战也可以走完旅程。

## 财务规则

`dist/engine.js` 是财务规则唯一实现，界面展示引擎结果。每轮按以下顺序执行：

1. 校验家庭选择、配置与购置预算，支付年初家庭和房车购置；必要时出售金融资产筹资。
2. 再平衡模式执行目标配置并计成交费用；维持持仓模式保留原持仓。
3. 对实际持仓应用年度回报，计算房价变化、车辆折旧和按揭本息。
4. 结算工资、生活支出、保障赔付与家庭事件；现金不足时变现，仍不足才新增缺口借款，有结余则偿还旧借款。
5. 更新下一年收入、开支与生活值，保存完整快照。

每年核对：**年末净资产 = 年初净资产 + 家庭净投入 + 投资与资产变动**。金融组合回报以实际年初投资本金计算；按揭本金和利息分列，交易费用计入投资与资产变动。

家庭、保障、房车与现金收益含教学假设。2007–2018 行业采用 French 研究组合，2019–2025 采用 XLK/XLY/XLV 代理，两阶段口径在资料室标明；2026 使用模拟回报。当前不提供个股、卖空、日内交易、卖房卖车和提前还贷。

## AI、切换与存档

三种服务共用固定中继和同一游戏协议。每轮一份成功回答包含情报分析、玩家建议和同桌决定；通关另生成画像。分析强调清楚的判断、可执行配置和家庭预算影响，观察原文绑定情报 ID，画像证据绑定实际选择记录。

成功结果在年度揭晓前封存。刷新、换模式或切换配置保留已有结果；新服务或模型用于下一份未封存请求。切换服务清空旧密钥，账号已开通的自选模型可保留。未连接模型时使用规则陪练，失败后也可明确选择规则，界面显示实际来源。

密钥只留页面内存，经中继临时转交，不进入存档、导出或仓库；刷新需重填。EFUND 单次年度/画像输出上限为 4,000 / 6,000 token；其他服务为 2,500 / 3,500 token。API 按服务商计费，重试可能重复计费；请求与恢复设置见 [RELEASE](RELEASE.md)。

EFUND 的网关 520、响应前连接重置和明确的流式传输中断可在同一三次/六十秒预算内恢复，按 4 秒、8 秒等待；格式、截断及规则校验失败不自动重试。持续的上游故障仍可能使操作失败，错误可附安全的网关诊断编号。AI 状态变化只更新相关卡片或提示，保留账本图表、相册图片、手动配置控件、滚动位置与焦点；退出画像请求会清除旧错误。

v1.0 沿用 v3 财务规则、数据版本、存档键和既有封存记录。双方结算一起提交，恢复时逐年重放核对。导出用于留档，当前没有文件导入或跨设备同步。

## 后续规划

| 方向 | 计划 |
| --- | --- |
| 体验迭代 | 根据正式版使用反馈改进情报呈现、分析质量、移动布局与接口兼容。 |

| 完整人生 | 扩展至约 60 次选择，加入退休现金流、多地区、税费和币种。 |

每次模块变更同步本页、[MODULES](MODULES.md) 和相关数据说明。独立 audit agent 复核决策、结算、存档与比较逻辑；验证范围记录于 [AUDIT](AUDIT.md)，发布信息记录于 [RELEASE](RELEASE.md)。
