# 素材与界面截图

## 代码原生视觉

图标与角色头像使用内联 SVG；组合分布为 CSS 环形图；财富曲线为 SVG，悬浮年末节点可查看金额。配置滑杆实时更新实际执行比例与预算，年度结算金额使用 requestAnimationFrame 插值。装饰动效不影响游戏结算。

## 2026-11-16 · v0.9 时代切片主题重编

当前清单覆盖 2006–2026，仍为 21 项：**17 张真实历史照片、3 幅历史主题原创图解、1 幅架空终章插画**。开局显示 2006 背景，完成 20 回合后的相册含 2007–2026 的 20 项。年初只展示上一年主题，当年素材结算后解锁。只调整媒体，不改变年度资产收益、家庭剧情或结算规则。

航天主题仅保留 2006 新视野号和 2012 好奇号两项；2017 为自然天文现象，即使将其合并计算，也只有三项。2018 以后改为体育、社会行动、城市生活、公共健康、物价、AI、内存产业、电动出行，不再连续使用太空任务。标题与旁白是项目原创，不是历史人物引语。

### 元数据与时点规则

`dist/media.js` 保持 `HISTORY_MEDIA[year]` API，增加 `theme` 及可选 `factSources: [{title,url,publishedAt}]`。所有当前资源保存本地 SHA256。

- `kind: historical`：真实照片，`capturedAt` 是拍摄日期；署名、许可、原图页面、下载 URL 保留。
- `kind: illustration`：原创历史图解，`capturedAt: null`；`eventDate` 是当年事实公开日期，`createdAt` 是真正制作日。`date` 同时显示两者，不能标为拍摄时间。
- `kind: scenario`：2026 架空终章。沿用纸页、港湾和路径的原创 SVG，并明确“模拟终章 / SIMULATION”。`createdAt` 为制作日；兼容字段 `capturedAt` 不代表真实事件摄影。没有捏造尚未结束的 2026 全年历史。

历史主题所依据的事件/官方公告和照片实际拍摄时间均不晚于对应年份年末。Commons 归档上传可能晚于拍摄（例如 2021 接种照片于 2023 年上传）；这类图片是事后归档的历史回望材料，不声称是当年已公开的新闻证据。原生图解同样属于后来制作的历史说明，只据当年事实绘制，不把后续产品、市场表现或 2026 年信息藏入图中。当年素材只在该年结算后解锁，不进入年初 AI 决策材料。
