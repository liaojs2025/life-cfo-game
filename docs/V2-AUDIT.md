# v2.0 独立发布审计

2026-11-25。审查对象为 GitHub Pages 客户端、社区统计 Worker 与数据库、两国开年资料和年度结算页。四条路线的本地验收通过，完整测试 252 项通过。最终调整汇率信号后，14 项本版定向测试再次通过。

## 财务、存档与时间边界

- 独立使用同一种子走完两国的十期和四十期，全程持有无息现金。按初始资金加各年工资、意外收入、减各年家庭支出逐笔加总，四份最终余额均等于服务端复算结果，配置累计回报均为零。原有测试另覆盖交易费、行业切换、变现、破产和风险指标。
- 四条路线均收在 2026 年 9 月 30 日。收益曲线包含该截至期，年频夏普及最大回撤采用完整年份。新闻与产业侧记早于当次决策，收盘锐评在结算后解锁。
- 检查 80 组、共 240 个开年读数的观测月份、可用日期、公开来源与传给模型的信号。美国早期失业率采用当期实时快照。日本早期 17 期改用当时的公开汇率，后来汇编的失业率放在结算回看。政策目标区间中点及极低的隔夜利率都保留实际小数。
- 用旧版本封存的决策续玩，经首轮回放、切换到新版情报、保存和刷新后，账本和配置连续。浏览器通过两国两版本的 100 次年度结算与终局导航。

## 玩家足迹与请求边界

- 统计以页面打开或刷新计浏览，以完成所选全部期间计通关，提前破产另列。两位访客可看到共同的总数和最近四局成绩。
- 服务端只接收访问随机码、一局种子、路线和年度整数配仓，由本身的账本复算成绩。通关、提前破产、缺少年份和本局重复提交均有本地验证。结果表仅保留局标识摘要、路线、结局、结束年、期末净资产、组合累计回报和登记时间；公开展示六个成绩字段。
- 独立模拟「服务端已经登记，客户端在收到确认前掉线」。本地仅保留待传的四项游戏资料；联机重试收到确认后移除，数据库通关仅加一。另一位玩家进入后，主动刷新能读到新的浏览总数。来源白名单、请求大小、参数化写入与严格字段校验经过源码复核。
- 浏览量反映页面访问。它允许同一位玩家隔天再开一局或刷新，不能估算独立人数。成绩由服务器根据有效的游戏输入复算，公开统计适合观察社区游玩情况。

## 趣味性、投教与视觉复核

- 80 张年度照片均在本地 Chrome 成功解码，80 个原图档案地址、文件路径、SHA-256 各自唯一。进一步比较了 3,160 对照片的 64 位视觉差异指纹，最小差异 17 位。照片保留实拍日期和图注，资料照片可与当年画面区分。
- 80 句锐评逐条校验为单句，有引用的资产或基准涨跌均能从当期行情精度复现。2026 年的锐评写明截至九月底。美国 2023 年的科技行情配合年初 ChatGPT 侧记，文字把单家公司与整个行业的成绩分开。
- 复核发现 23 张年度头条的末句与同屏开年背景重复，发布版卡片去掉了该段，展开详情保留全文。匿名成绩注明组合回报为扣费前口径，避免与已计费用的家庭净资产混读。
- 320 像素宽实测开年数据展开面板落在横坐标 17–295 内，页面无横向滚动，图片正常解码。390 像素投资台和桌面结算账单另有截图。手机的「去配仓」可跳过长文，直接到配置区。

## 复查方式

### 首页收益榜与 AI 对手席补充审计

本次小更新通过 255 项测试。真实 Chrome 在 320、390、1360 像素宽度验证近期四局、榜单顺序和北京时间，旧成绩可参与排名。离线新局确认保留首次结束时间，升级前缓存的终局仍可登记。测试数据库从旧结构连续运行两次迁移后原数据完整。破产局仅进入近期记录。

用模拟模型完成十期对局：连接失败时等待玩家选择，当期明确转入规则托管；下一期模型成功后，即使切回规则并刷新，已封存的决定仍标为模型驱动。终局汇总为模型驱动一期、规则托管九期。付费调用为零。

运行 `npm test` 和 `python3 scripts/build-opening-indicators.py --check`。发布回归包括 [独立现金账本与断网确认](../tests/v2-release-audit.test.js)、[社区计数和服务端回放](../tests/community.test.js)、[决策封存](../tests/desk-v2.test.js)、[开年口径](../tests/opening-indicators.test.js)、[新闻照片](../tests/atlas-photo-unique.test.js)和[逐年文案](../tests/era-notes.test.js)。
